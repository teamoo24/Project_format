# Project_format

新しいゲームを始める前に、エージェントへ渡す型。  
Ariadne で育てた進め方を、次の作でも使えるようにしたもの。

最初は Godot の構造をつかむためにレッスン式（本人が全部手を動かす）で進めた。構造が見えてきたので、今は **報告式**。エージェントが1つずつ作って報告し、本人が F5 で遊んで判断する。

## 3ファイルの役割

| ファイル | 書く人 | 役割 |
|---|---|---|
| `AGENTS.md` | エージェント | 作り方、事故を防ぐ、報告の形、今作だけのこと |
| `PLAN.md` | 共同 | 全体の地図。「次の手」は小さな変更の列 |
| `README.md` | 本人向け | 今のメモ。「できたこと」「いまの手」「決めてほしいこと」 |

型の中身:

- [SKILL.md](SKILL.md) … 報告式のルール（エージェントが先に読む）
- [agents-template.md](agents-template.md)
- [plan-template.md](plan-template.md)
- [readme-template.md](readme-template.md)

## エージェントへの頼み方

このレポを開いて（または `SKILL.md` を渡して）:

```
新しいゲームを始めたい。報告式で型を埋めて。
```

始まったらゲームのレポで「次」「OK」、または直してほしいことを返す。

## アイデアから型（エージェント向け）

まだゲーム本体は作らない。会話で穴を埋め、3ファイルを作る。

### 1. 核だけ聞く

- 誰が作るか
- エンジン（Godot など）
- 一言で何のゲームか（本人の言葉）
- 形の参考（ブラウザ版のリンク）。**参考を作り直さない**
- 参考と同じところ / 今作だけにするところ

### 2. 足りないぶんを聞く

- ゲーム名、レポ名
- 今のメインシーン、手本の脚本、コメントの言語
- 後回し（タイトル、セーブ、ギャラリーなど）
- 触らない試作フォルダ（なければ無し）
- 売り方の目安（なければ書かない）
- ここまでできたこと（なければ「まだ何もない」）

本人が言っていないものは、勝手に埋めない。

### 3. 型をコピーして `{{}}` を全部埋める

1. `agents-template.md` → `AGENTS.md`
2. `plan-template.md` → `PLAN.md`
3. `readme-template.md` → `README.md`

`{{}}` は残さない。不要な節は削除する。

### 4. 最初の手を1つ決める

`PLAN.md` の「次の手」は、F5 で見える変化が1つの列にする。  
本人が「これで」と言うまで、シーン・UI・脚本は作らない。

### 5. 渡し方

ゲームのレポがある → そこへ3ファイルを置く。  
まだない → 3ファイルの中身を出し、本人がレポを用意してから置く。  
このフォーマットのレポのテンプレは上書きしない。

## 作り始めたら

ルールは [SKILL.md](SKILL.md)。ゲームのレポに `AGENTS.md` があればそちらを優先。

1回に1つ作り、「変えたこと」「F5 で見るところ」「本人の残作業」で報告する。OK をもらったら README と PLAN を更新し、commit / push。

## しないこと

- 複数の機能をまとめて入れて「全部できた」にしない
- 本人の OK を待たずに次へ進まない
- 数値・素材・大きなノード構成の変更を勝手に確定しない
- 参考を丸ごとコピーして今のシーンを捨てない
- タイトル・セーブ・ギャラリーなど後回しを核より先に足さない
